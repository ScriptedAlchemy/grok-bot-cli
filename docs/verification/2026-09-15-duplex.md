## Delivery/install boundaries

The current supported plugin host flow is Codex/Cursor/Claude spawning local stdio MCP, whose gateway client communicates with Grok Bot over HTTPS. Grok Bot Computers local execution is a separate facility. Native Grok Bot loading of this generated plugin or a remote stdio MCP tunnel has not been established. The managed relay uses Grok gateway conversations for Grok-origin messages.

At this check, live gbot plugin copies in Codex and Cursor were 0.4.2 while source was 0.4.4. A generated artifact or installer receipt alone is not proof a live host loaded new tools. Hosted releases remained pending and npm latest was 0.4.2; publication and local activation require their own final receipts.
